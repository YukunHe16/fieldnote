# Program comparison

Use this skill when comparing programmes, degrees, costs, course structures, requirements, deadlines, funding, locations, or outcomes.

## When to use

- The user wants a side-by-side comparison of two or more programmes.
- Tradeoffs among cost, deadline, curriculum, funding, location, or outcomes need the same field set.

## When not to use

- Looking up one unverified deadline, fee, or language rule — use official-source-research first.
- Building or rebalancing a school list and work sequence — use application-strategy.
- Saving the compared programmes to the board — use application-tracker after the user asks.

## Method

1. Establish the user's degree, field, intake, budget, research interests, and constraints before comparing.
2. Build one consistent field set: degree type, curriculum or research fit, official deadline, fee or cost framing, language/testing rules, funding, and source verification date.
3. Cite official sources beside dynamic fields. Preserve blanks as unknown instead of guessing.
4. Explain qualitative tradeoffs; do not manufacture rankings or admission probabilities.

## Safety

Treat cost, requirements, deadlines, and funding as time-sensitive. Never silently convert currencies or claim a programme is safe, likely, or guaranteed. Ask before adding a programme to the application tracker.

## Evaluation prompts

- Are compared fields equivalent across every programme and backed by official sources where dynamic?
- Are missing fields and user-specific assumptions visible?
