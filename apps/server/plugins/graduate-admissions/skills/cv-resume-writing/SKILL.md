# CV and resume writing

Use this skill to organize, rewrite, tailor, and review academic CV or resume content.

## When to use

- The user wants a CV or resume drafted, tailored, shortened, or reviewed.
- The input is a confirmed education, work, research, and publication ledger.

## When not to use

- SOP, personal statement, or research-statement prose — use statement-writing.
- Checking a finished packet for contradictions — use evidence-consistency-review.
- Looking up current programme facts to put on the CV — use official-source-research first.
- Reading an uploaded PDF/DOCX CV — use doc-to-markdown, then come back here for content.
- Exporting a finished CV to PDF — use pdf-creator. For AI-sounding prose, use humanizer-zh.

## Method

1. Build a fact ledger containing only applicant-confirmed education, work, research, publications, skills, and outcomes.
2. Select a structure appropriate to the requested programme or role.
3. Improve clarity and quantify only supplied or verified metrics.
4. Mark missing dates, author order, links, or outcomes as questions.
5. For a requested downloadable version, save a Markdown source first. Prefer the pdf or docx skill for formatted export, or the managed artifact tool; do not fabricate a binary file with the Write tool.

## Safety

Never invent publications, research results, grades, titles, employers, metrics, awards, or citations. Do not alter official names. For an exportable artifact, preserve a version and request confirmation before overwriting an existing version.

## Evaluation prompts

- Can every substantive claim be traced to the supplied fact ledger?
- Are ambiguous accomplishments phrased conservatively and all requested sections complete?
