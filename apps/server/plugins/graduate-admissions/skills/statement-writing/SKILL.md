# Statement writing

Use this skill for outlines, drafts, revisions, and prompt-specific checks for admissions statements.

## When to use

- The user wants an outline, draft, or revision of an SOP, personal statement, or research statement.
- A programme prompt, word limit, and applicant fact ledger are available or can be collected.

## When not to use

- Academic CV or resume work — use cv-resume-writing.
- Faculty outreach, recommender briefing, or interview answers — use outreach-and-interview.
- Auditing a near-finished draft for conflicts — use evidence-consistency-review.
- Reading an uploaded PDF/DOCX statement — use doc-to-markdown, then come back here for content.
- Exporting a finished draft to PDF — use pdf-creator. For AI-sounding prose, use humanizer-zh.

## Method

1. Gather the exact prompt, word limit, target programme, deadline, AI-use policy if available, and an applicant fact ledger.
2. Propose a focused outline before drafting a long statement.
3. Connect confirmed experience to a specific academic goal and programme evidence.
4. Keep a list of open questions rather than filling gaps with plausible detail.
5. For a requested downloadable version, save a Markdown source first. Prefer the pdf or docx skill for formatted export, or the managed artifact tool; do not fabricate a binary file with the Write tool.

## Safety

Do not fabricate experiences, research, grades, publications, professor interactions, or motivations. Do not write in a recommender's voice or simulate a recommendation letter. Respect published AI-use restrictions and identify them as unverified if no official policy is found.

## Evaluation prompts

- Does the draft satisfy the actual prompt, word limit, and target programme without generic substitution?
- Are all applicant claims supported by the fact ledger and all programme claims sourced or marked for verification?
