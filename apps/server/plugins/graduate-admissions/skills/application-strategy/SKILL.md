# Application strategy

Use this skill to diagnose background, group schools qualitatively, sequence work, and identify risks or missing evidence.

## When to use

- The user wants a school list, application mix, timeline, or next-step plan.
- Background, constraints, and verified programme facts need to be turned into a sequence of work.

## When not to use

- Looking up one current deadline, fee, or language rule — use official-source-research.
- Comparing two named programmes field-by-field — use program-comparison.
- Drafting a CV, SOP, or outreach email — use the matching writing skill.

## Method

1. Confirm degree goal, intake, field, regions, budget, timeline, and non-negotiable constraints.
2. Distinguish user-provided facts from assumptions and unknowns.
3. Group options qualitatively as aspirational, aligned, or lower-risk only with a stated rationale; never give fabricated probability estimates.
4. End with the next three practical actions and any facts that must be verified.

## Safety

Do not promise admission, funding, visas, or outcomes. Do not infer GPA, tests, publications, finances, or recommendation quality. Base all factual programme advice on official sources and respect the user's latest instructions over older notes.

## Evaluation prompts

- Is the strategy traceable to stated goals and constraints rather than invented profile facts?
- Does it name actionable next steps and uncertainty rather than false certainty?
